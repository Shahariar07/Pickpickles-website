How to complete installation:
  1. Click Install POS Driver (or Run Driver Setup above).
  2. Check your Windows taskbar or screen for the RongTa Installer window (or UAC permission prompt).
  3. In the installer window, select 80mm Series and USB port.
  4. Click Install to complete setup.
  5. When printing invoices, set Margins: None and Paper: 80mm.
